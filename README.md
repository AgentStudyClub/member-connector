# 에이전트 스터디 클럽 회원 커넥터 설치기

회원 커넥터를 처음 설치할 때 쓰는 설치기입니다. 호스트 앱이나 기기 관리자가 미리 등록한 공식 GitHub 저장소, 릴리스 태그, 첨부 파일 이름과 해시를 기준으로 설치기를 확인합니다. 이 안내의 링크나 파일만으로는 검증에 필요한 사전 등록이 완료되지 않습니다.

## 처음 설치하는 경우

1. 호스트 앱이나 기기 관리자가 이 저장소의 변경 불가 릴리스에서 사전 등록된 `install-frozen.mjs` 첨부 파일을 가져옵니다. 설치기를 실행하기 전에 릴리스와 첨부 파일의 GitHub 증명 및 사전 등록된 SHA-256을 모두 확인합니다.
2. 클럽의 회원 화면에서 안내한 커넥터 ZIP을 준비합니다. 검증을 마친 설치기는 ZIP의 SHA-256과 발행자 서명, 판본, 만료 시각 및 ZIP 안의 각 파일을 확인합니다. 두 단계 검증이 끝나면 새 폴더에 커넥터를 준비하고 잠금 파일 기준으로 의존성을 설치한 뒤 진단을 실행합니다.
3. 설치가 완료되면 클럽 회원 화면으로 돌아가 기기 연결을 진행합니다. 대화 앱에 도구를 등록하거나 활동 권한을 추가하는 절차는 회원이 해당 작업을 허용할 때 진행합니다.

최초 설치 대상은 관리자가 신뢰 도구를 미리 구성한 macOS 또는 Linux 기기입니다. 호스트에서 Node.js 24, 시스템 `unzip`, 신뢰 가능한 npm과 GitHub 검증 도구를 준비합니다. 회원 연결 코드나 토큰은 GitHub에 입력할 필요가 없습니다.

새 설치 폴더는 회원 또는 시스템 관리자가 관리하는 경로에 두세요. 심볼릭 링크 없이 접근할 수 있고 다른 로컬 사용자가 바꿀 수 없는 상위 폴더를 사용합니다.

아직 승인 릴리스가 없거나 호스트에 검증 기준이 등록되지 않았다면 설치를 보류하세요. 기존 설치가 있는 경우에는 처음 설치할 때 확인한 경로를 그대로 사용하세요.
